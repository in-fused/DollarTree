Project Import

Upload a CSV and seed a project directly into Supabase using the same store model consumed by the operations console. The importer tolerates extra vendor columns, normalizes common field-name variants, and geocodes missing coordinates when a usable address is present.

Required per-row data: store_id and either valid lat/lng coordinates or a usable address. Extra columns are ignored safely. Common field-name variants for store ID, address, city/state/zip, region, territory, latitude, and longitude are normalized automatically.
  • Unknown columns are ignored and never block import on their own.
  • Optional metadata like region/territory/state only raises warnings when partially present.
  • Status rows are seeded as active by default so imported projects can update immediately.
  • Activity events are seeded for imported stores so project history starts cleanly.
